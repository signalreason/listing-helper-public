# Use eBay Listing Assistant

Open the address supplied by your app operator and sign in. Use one browser profile
for each app account. Keep your original item photos in a separate location.

## Make a listing

1. Select 1–24 photos, at most 12 MB each. Put the best overall view first. Include the
   label, size, material, and any damage. You can reorder the photos.
2. Add a short note for facts the photos cannot show, such as a missing part or a flaw.
3. Select **Men**, **Women**, or **Kids**, then the category that matches the item.
4. Select **Generate listing** and wait for the draft.
5. Review the title, description, condition, item specifics, and price. Confirm facts
   against the item. Fill in missing required fields. A price estimate is not a sold-price search.

Changing a draft's category requires generation again before publication. Review the
new result because generation can replace generated listing fields.

## Save and return later

Watch the save status. Do not close the page while it says **Not saved**. Use **Save now**
to retry. If saving still fails, copy the text somewhere private before leaving.

Open a saved draft from **Drafts**. Text is stored on the server. Original photos are
stored in the browser profile that saved them, with a total limit of 1 GiB for the site.
They do not transfer to another phone, computer, browser, or browser profile. Clearing
site data, private browsing, or browser storage pressure can remove the copies.

## Publish on eBay

Connect your eBay account if you have not done so. Select the listing condition and
existing shipping, payment, and return policies. Enter price, package weight in pounds
and ounces, and package dimensions in inches. Positive fractional dimensions round up
to whole inches. Check the saved values before publication.

Read each missing-field instruction. When the listing is complete and publication is
enabled, select **Publish live on eBay**. The app checks the listing with eBay, uploads
photos, and requests publication. This creates a live listing, not a Seller Hub draft.

After success, use the link to check the listing on eBay. The saved app draft becomes
read-only. Use Seller Hub for later changes, orders, shipping, returns, and messages.

You can also copy listing text and create a listing manually in Seller Hub.

## Delete a draft

Deleting a draft removes its saved app data and the local photo copy available to this
browser. It does not end or change a live eBay listing. Use Seller Hub to end a listing.
If browser storage is unavailable, follow the warning about remaining local site data.

## When something goes wrong

| What you see | What to do |
| --- | --- |
| Missing photos after opening a draft | Use the original browser, or select the original complete photo set again in order. |
| Storage is full | Keep originals separately, then delete app drafts you no longer need. |
| Required fields or disabled publication | Read the reasons beside the fields; check condition, item specifics, policies, and package details. |
| eBay is disconnected | Reconnect through the app. Ask the operator to check environment settings if it fails. |
| Category menu cannot load | Use **Retry categories**. Ask the operator for help if it still fails. |
| Generation limit reached | Wait as instructed. Limits are 24 starts per hour and 30 per day per account. |
| AI service unavailable | Ask the operator to check billing and the API service. Do not keep pressing Generate. |
| Publication result is uncertain | Keep the saved draft. Use its recovery retry and check Seller Hub. Do not create a replacement listing while the result is uncertain. |
| Password lost | Ask the operator. The owner can reset the second account; no reset email is sent. |
| Drafts disappear after database loss | Ask the operator. Browser photos alone do not restore server records. |

For help, follow [the support guide](../SUPPORT.md). Remove private information from any
report or screenshot.
